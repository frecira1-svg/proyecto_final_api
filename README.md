# Proyecto Final API - Rick and Morty

## 📌 Descripción
Este proyecto es una aplicación web que consume la API pública de Rick and Morty para mostrar información de personajes.

Permite buscar personajes por nombre y visualizar sus datos en tarjetas.

## 🚀 Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await

## 🌐 API utilizada
https://rickandmortyapi.com/

## ⚙️ Funcionalidades
- Mostrar personajes al cargar la página
- Buscar personajes por nombre
- Mostrar resultados en tarjetas
- Manejo de errores cuando no hay resultados
